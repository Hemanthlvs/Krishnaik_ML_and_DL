## R-Squared and Adjusted R-Squared Performance Metrics

### 1. R-Squared (R²)

**Definition and Purpose:**
*   R-squared is a performance metric used to evaluate how well a model is performing.
*   It helps to find out how accurate your model is.
*   **A higher R-squared value (closer to 1) indicates a more accurate model**. For example, 0.70 means 70% accuracy, and 0.90 means 90% accuracy.

**Formula:**
*   R-squared is calculated as: `1 - (Sum of Squared Residuals / Sum of Squared Total)`.
    *   `R² = 1 - (SS_residual / SS_total)`.

**Components of the Formula:**
*   **Sum of Squared Residuals (SS_residual):**
    *   This represents the **sum of the squared differences between the true output points (y_i) and the predicted points (y_i_hat)**.
    *   `SS_residual = Σ (y_i - y_i_hat)²`.
    *   `y_i` are the true output data points.
    *   `y_i_hat` are the predicted points generated by the best-fit line.
    *   The difference between `y_i` and `y_i_hat` is called the **residual or error**.
    *   When the best-fit line is good, this difference (SS_residual) will be a **smaller number**.

*   **Sum of Squared Total (SS_total):**
    *   This represents the **sum of the squared differences between the true output points (y_i) and the average (mean) of all true output points (y_i_average)**.
    *   `SS_total = Σ (y_i - y_i_average)²`.
    *   `y_i_average` is the mean of all true output (y_i) points.
    *   The difference between `y_i` and `y_i_average` will generally be a **bigger number** compared to the residual.

**Interpretation of the Formula:**
*   Since the sum of squared residuals (numerator) is a smaller number and the sum of squared total (denominator) is a bigger number, their division will result in a smaller number.
*   Subtracting this small number from 1 will result in a value close to 1, indicating a good model.

**Problem with R-squared:**
*   R-squared has a limitation: **it tends to increase as you add more independent features to your model, even if those features are not correlated or relevant to the output**.
    *   For example, adding 'gender' as a feature to predict 'house price' (where there's no correlation) might still lead to a slight increase in the R-squared value.
    *   This can give a misleading impression that the model is performing better, even when irrelevant features are included.
    *   This issue is related to **overfitting**.

### 2. Adjusted R-Squared

**Purpose and Difference from R-squared:**
*   **Adjusted R-squared addresses the problem of R-squared increasing with irrelevant features**.
*   **It penalizes the model for including features that are not correlated with the output feature**. This makes it a more reliable metric for models with multiple features.

**Formula:**
*   Adjusted R-squared is calculated using the formula:
    `Adjusted R² = 1 - [(1 - R²) * (n - 1) / (n - p - 1)]`.

**Components of the Formula:**
*   `n`: The **number of data points** in the dataset(number of rows).
*   `p`: The **number of independent features** (or input variables) being used in the model.

**How it Solves the Problem (Key Behavior):**
*   **If you add an irrelevant independent feature (one not correlated with the output), the Adjusted R-squared value will decrease**. This is because the 'p' value (number of independent features) increases, which impacts the division in the formula.
*   **If you add a relevant independent feature (one directly proportional/correlated to the output), the Adjusted R-squared value will increase**.
*   This behavior helps to identify when a model is becoming overfit by including unnecessary features.
